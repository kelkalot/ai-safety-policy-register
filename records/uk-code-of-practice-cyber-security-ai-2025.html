Summary

A voluntary baseline of cyber security requirements for AI systems, including generative AI. It has 13 principles across five lifecycle phases: secure design, development, deployment, maintenance and end of life. It is intended as the basis of a global ETSI standard.

Status notes

Published with an Implementation Guide. The government said it would submit the Code to ETSI and update it to match the final ETSI standard. Whether the ETSI standard has since been published was not verified here.
