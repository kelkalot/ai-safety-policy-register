# Content-quality check of the records added after the first commit (data/records.json, version 1.4, 285 records)

Scope: the 71 records whose IDs are not in `git show cbcd342:data/records.json` (214 records). That is the 70 records of the six research passes (12 Europe, 12 international, 31 Asia/Americas/Illinois, 15 Middle East and Africa) plus US-28 (NSPM-11), which the re-verification commit 44ac36d added while this check was running. How it was done: all 71 records were read in full. The old records' current versions were diffed against the post-QC commit 9cc2540 to catch regressions. The seven level-C official URLs were requested live on 12 October 2026 (curl with a browser user agent; one WebFetch each for the two JavaScript sites). Two web searches were run (VN-07 official text, TH-01 hearing page) before the session's search budget ran out, so US-27 and the Maine adjournment date were not searched.
